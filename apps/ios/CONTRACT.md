# Current implementation contract

WayPoint is an iOS 17+ SwiftUI/MapKit app with a dependency-free pure Swift package and account-isolated persistence. The connected mode is pinned to the isolated Cloudflare D1 staging origin. Production remains KV; never enable whole-trip legacy uploads or use production credentials/cache in this staging protocol.

Core live state: D1Workspace with authorized entity base, per-record revisions, opaque cursor and immutable submitted outbox. LocalWorkspace remains the demo/legacy presentation model; its queue is not a D1 encoder. AppModel maps D1 state into native views, performs identity validation, collects complete bootstrap pages, commits changes/cursor together and persists requests before sending. One mutation is sent at a time; conflicts require explicit resolution. Writes and editing are serialized by busy state.

The existing Xcode project, local WayPointCore package, shared scheme and app-hosted tests are generated by scripts/generate_project.py. Keep target source membership aligned after adding files. Run swift test plus scripts/check-mac.sh on macOS; static parsing here is not evidence of a successful Apple SDK build.

Source-only scope: no Cloudflare deployment, production switch, signing identity, distribution package, photos or Android implementation. Backend source/rehearsal remains separate. Current source files and docs/VALIDATION.md supersede the original September 23 read-only framework contract.
