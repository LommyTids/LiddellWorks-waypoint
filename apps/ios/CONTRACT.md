# Current implementation contract

WayPoint is an iOS 17+ SwiftUI/MapKit app with a dependency-free pure Swift package and account-isolated persistence. Connected mode uses the production Cloudflare D1 origin at liddellworks.com/WayPoint. Production and staging have separate session/cache namespaces. Never enable whole-trip legacy uploads or mix environment credentials/cache.

Core live state: D1Workspace with authorized entity base, per-record revisions, opaque cursor and immutable submitted outbox. LocalWorkspace remains the demo/legacy presentation model; its queue is not a D1 encoder. AppModel maps D1 state into native views, opens the saved copy first, performs identity validation, collects complete bootstrap pages, commits changes/cursor together and persists requests before sending. One mutation is sent at a time; conflicts require explicit resolution. Writes and editing are serialized by busy state.

The existing Xcode project, local WayPointCore package, shared scheme and app-hosted tests are generated by scripts/generate_project.py. Keep target source membership aligned after adding files. Run swift test plus scripts/check-mac.sh on macOS; static parsing here is not evidence of a successful Apple SDK build.

The Atlas interface uses phone/code authentication and record-level sync, and offers Apple and Google sign-in once the server names an app client ID for them. The Google token exchange at `oauth2.googleapis.com` is the only call to a host other than the production origin, and sends no WayPoint credential. Phone login no longer reaches the site owner's account, and the move to Apple and Google is described in `docs/backend-v1/sign-in.md`. Settings can delete the signed-in account, and that account's local copies go only after the server confirms. Participant filtering is presentation over authorized records, never a permission grant. Account/traveller administration and expenses remain web workflows. No Cloudflare deployment, production switch, device signing identity, distribution package, photos or Android implementation is included. Backend source/rehearsal remains separate. Current source files and docs/VALIDATION.md supersede the original September 23 read-only framework contract.
