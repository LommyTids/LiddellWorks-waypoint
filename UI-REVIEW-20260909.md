## Plain-language changes

- Find location remains usable after cancelling a search by typing a new query.
- Opening a pin editor no longer silently changes the saved location or invents a pin at 0,0.
- View on map can switch to Set pin; an actual click/drag is required to change coordinates.
- Selecting another location clears the previous area's boundary. Slow old responses cannot overwrite a newer selection.
- Closing or rebuilding forms cleans up searches and maps.
- Refreshing flight information preserves a reviewed pin for the same airport, but updates the pin when the route changes. Responses for changed flight/date inputs are ignored.
- Expense rows have edit actions in both desktop tables and mobile ledgers. Only standalone expenses expose Delete; linked costs open the activity, transport or accommodation editor.
- Invalid currency codes, whitespace-only required text and nonpositive exchange rates stay as local field errors, rather than failing a save and locking editing.
- Exchange rates accept useful precision such as `0.0052`; ordinary amounts keep their two-decimal input step.
- Keyboard focus excludes hidden controls, reveals collapsed sections containing invalid fields, and returns to a page heading when a save replaces the original button.
- Escape closes autocomplete before the dialog. Suggestion selections refresh dependent controls.
- Hidden location summaries remain hidden even when their component uses flex layout.
- Phone flight lookup fields wrap; Journey date/time boxes stack; modal actions use the available viewport height; map layers stay below navigation and dialogs.
- Sticky headers account for the real height of the top bar and offline/error banner.
- Offline status uses the actual message and disables Save while preserving the form.
- Settings includes Edit trip details on phones, a shared accessible currency combobox and a collapsed direct-dependency inventory.

## Technical details

The application remains a framework-free HTML/JavaScript frontend. No new runtime packages, paid services, backend schema changes or production-data migrations were added.

Location requests and boundary results are scoped to their picker lifecycle. Abort cleanup restores button/busy state independently of the cancelled request's `finally` block. Boundary requests use abort signals plus identity/connectivity checks. Leaflet instances are disposed before modal teardown or reactive field replacement. Empty coordinate strings are not converted to zero; legitimate zero-valued coordinates remain valid.

Expense aggregation adds in-memory source references solely for rendering actions. CSV columns and persisted trip records are unchanged. Linked cost deletion is deliberately not exposed from the ledger.

Native disclosures, form constraints and existing semantic tokens are retained. Input/change validation shares cleanup, suggestions dispatch `change`, focus candidates use visibility checks, and ResizeObserver feeds measured sticky offsets into CSS variables.
